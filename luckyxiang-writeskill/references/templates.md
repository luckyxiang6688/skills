# Skill 模板库

## Frontmatter 模板（所有类型共用）

```yaml
---
name: luckyxiang-{skill-name}
description: |
  {一句话描述}。
  支持 {输入格式} 等多种输入格式。
  输出 {输出格式}。

  USE FOR: {触发词1}、{触发词2}、{触发词3}、{触发词4}、{触发词5}。
  {补充触发说明}。

  DO NOT USE FOR: {反触发词1}（用 {替代skill1}）、{反触发词2}（用 {替代skill2}）。
version: "1.0"
author: luckyxiang
tags: [{tag1}, {tag2}, {tag3}]
---
```

### Frontmatter 规则

- name 格式：`luckyxiang-{skill-name}`，kebab-case
- description 长度：≥ 300 字符（howskill user_experience 要求）
- USE FOR 触发词：≥ 3 个（howskill trigger_design 要求）
- DO NOT USE FOR 反触发词：≥ 2 个
- tags：2-5 个，从 skill 类型和功能中提取
- version：初始版本 "1.0"

## 类型 1：content_creation（内容创作类）

**适用场景**：生成报告、文章、解读、文档等输出内容的 skill。

**典型 skill**：deepreport, plainreport, writer

### SKILL.md Body 模板

```markdown
# luckyxiang-{skill-name}

> {一句话描述}。独立运行，{核心特色}。

## 概述

luckyxiang-{skill-name} 将{输入描述}自动转化为{输出描述}。核心特色：{特色1}；{特色2}；{N}步工作流含不可跳过的{关键步骤}步骤；完全独立运行，不依赖其他 skill。

## 快速参考

| 命令 | 说明 |
|------|------|
| `/{skill-name} <路径>` | 完整{功能} |
| `/{skill-name} <路径> --topic "主题"` | 指定{主题} |
| `/{skill-name} <路径> --output {output}` | 指定输出路径 |
| `/{skill-name} <路径> --auto` | 跳过确认，直接生成 |

## 示例

```bash
# 基本用法
/{skill-name} {示例路径1}

# 指定主题
/{skill-name} {示例路径2} --topic "{示例主题}"

# 指定输出
/{skill-name} {示例路径3} --output {output_file}

# 自动模式
/{skill-name} {示例路径4} --auto
```

## 工作流总览

```

...
步骤N: 组装输出 → {输出描述}
```

## 步骤 0：输入解析

从用户命令中提取：

1. **源材料路径**（必填）：支持 glob 模式和逗号分隔多路径
2. **{主题参数}**（可选，`--topic`）：默认从素材内容推断
3. **输出路径**（可选，`--output`）：默认源目录下 `<主题>-{output_suffix}`
4. **自动模式**（可选，`--auto`）：跳过确认，直接生成

### 文件扫描

- 如果输入是目录，递归扫描所有可处理文件
- 如果输入是 glob 模式，用 Glob 工具匹配
- 忽略不可处理的文件类型，列出被忽略的文件

## 步骤 1：{步骤1名}

{步骤1详细描述}

## 步骤 2：{步骤2名}

{步骤2详细描述}

## 步骤 N：组装输出

{输出格式描述}，严格使用 `references/{style_ref}` 中的样式系统。

### 输出规范

- 所有 CSS + JS + SVG 内嵌，零外部依赖
- UTF-8 编码，`lang="zh-CN"`
- 文件写入 `--output` 指定路径或默认路径

## 异常处理

| 场景 | 处理 |
|------|------|
| 文件不存在 | 立即报错，给出正确路径建议 |
| 文件无法读取 | 报告已读内容，标记不可读部分 |
| 素材严重不足 | 简化内容，标注素材不足的章节 |
| 单一源文件 | 减少子节深度，保持结构完整 |
| 源文件过多（>20） | 建议用户缩小范围 |
